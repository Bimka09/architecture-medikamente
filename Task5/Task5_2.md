# Cutover-план миграции (стратегия Branch by abstraction)

## **Целевая архитектура**

- Микросервисная архитектура с доменной декомпозицией:
    - `Patient Management`
    - `Appointment Scheduling`
    - `Billing & Payments`
    - `Lab Integration`
    - `Inventory (TMC)`
    - `Audit & Security`
- Централизованное хранилище: PostgreSQL + S3 для документов
- Шина событий: Kafka
- Аутентификация: Keycloak (с поддержкой SSO и MFA)
- Аудит и мониторинг: Elastic + VictoriaMetrics + Alertmanager
- Озеро данных: MinIO + Spark/Flink + ClickHouse

## Этапы миграции
