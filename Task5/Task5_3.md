# Меры по минимизации рисков

| Риск                                 | Мера по снижению                                                      | Ответственный                  |
|--------------------------------------|-----------------------------------------------------------------------|--------------------------------|
| Потеря данных при миграции           | Регулярные бэкапы, валидация через checksum, A/B-сравнение            | Data Engineer                  |
| Несоответствие законодательству      | Шифрование PII, RBAC, аудит, согласие на обработку данных             | Тех.директор, Юрист            |
| Сбои в работе новых сервисов         | Постепенное включение (feature toggles), канареечное развертывание    | DevOps                         |
| Отказ пользователей от новой системы | Обучение, пилотная группа, обратная связь                             | HR, Руководитель отдела        |
| Задержки в интеграции с 1С           | Раннее тестирование OLE-компонент, mock-сервисы                       | Инженер интеграционных решений |
| Утечка данных                        | Тегирование (data classification), DLP-политики, ограничение экспорта | Инженер интеграционных решений |

## План отката

- На уровне модуля: внедрение feature toggle
- На уровне данных: восстановить данные из ежедневного backup.
- Коммуникация: уведомление команды по рабочим каналам, создание incident report.
