# Задание 3. Оценка Data Encryption at Rest and In Transit

## 1. Определение и классификация данных

| Категория | Примеры | Риск | Защита |
|--|--|--|--|
| СПДн | Диагнозы, анализы, истории болезней | Очень высокий | Шифрование AES-256, строгий RBAC |
| PII | ФИО, паспорт, контакты | Высокий | Шифрование, маскирование |
| Аутентификация | Пароли, токены | Высокий | Хэширование bcrypt, Vault |
| Финансовые | Реквизиты, платежи | Высокий | Шифрование БД |
| ТМЦ | Медикаменты, цены | Низкий | Контроль доступа |

## 2. Базовые инструменты защита данных

1) TLS 1.3 - для внешних соединений
2) mTLS - для связи между микросервисами
3) Шифрование дисков (СDE) - защита от физической кражи
4) Шифрование БД (TDE)-  PostgreSQL с pgcrypto, шифрование бэкапов
5) Шифрование на уровне приложения - AES-256-GCM для критичных данных (СПДн, паспорт), ключи в Vault, очистка буферов после использования

## 3. Использование автоматизированного контроля

1) HashiCorp Vault
    - Управление секретами и ключами
    - Автоматическая ротация ключей

2) Service Mesh (Istio/Linkerd)
    - Автоматическое включение mTLS для всего трафика
    - Политика "запрещено по умолчанию"

3) Open Policy Agent (OPA)
    - Проверка конфигураций на безопасность в CI/CD
    - Контроль, что секреты не в открытом виде

4) Мониторинг (Prometheus + Grafana)
    - Отслеживание работы Vault
    - Мониторинг сертификатов TLS
    - Алерты при подозрительной активности

5) Контроль доступа
    - RBAC через Keycloak
    - Тегирование для автоматического контроля

6) Тегирование данных
    - Apache Atlas для автоматического тегирования в Hadoop
    - Интеграция с Keycloak (JWT атрибуты)


## 4. Реестр программных и аппаратных средств для защиты даных

| Тип данных | Инструменты для защиты |
|--------------|-----|
| СПДн в БД | Шифрование на уровне приложения (AES-256) + Vault |
| PII в БД | TDE (pgcrypto) или шифрование приложения |
| Данные при передаче | TLS 1.3 (внешние), mTLS (внутренние) |
| Пароли | Хэширование bcrypt, Vault для токенов |
| Бэкапы | Шифрование при создании, ключи отдельно |
| Диски | Полное шифрование (LUKS/BitLocker) |


## Итоговая классификация по защите данных

| Данные | В чём необходимость защиты | Инструменты защиты |
|--|--|--|
| Персональные данные больного | Репутационные риски, финансовые потери | Шифрование данных, контроль доступа, тегирование данных |
| Ключевая медицинская информация (например, известные аллергии, текущие лекарства) | Репутационные риски, финансовые потери | Шифрование данных, контроль доступа, тегирование данных |
| Согласие на обработку персональных данных больного | Репутационные риски, финансовые потери | Шифрование данных, контроль доступа, тегирование данных |
| Результаты лабораторных анализов | Репутационные риски, финансовые потери | Шифрование данных, контроль доступа, тегирование данных |
| Результаты медицинских обследований | Репутационные риски, финансовые потери  | Шифрование данных, контроль доступа, тегирование данных |
| Медицинское заключение по результатам приёма больного | Репутационные риски, финансовые потери  | Шифрование данных, контроль доступа, тегирование данных |
| Журнал записей на приём | Репутационные риски, финансовые потери | Шифрование данных, контроль доступа, тегирование данных |
| Данные сотрудников | Репутационные риски, финансовые потери | Шифрование данных, контроль доступа, тегирование данных |
| Платёжные данные больного | Репутационные риски, финансовые потери | Шифрование данных, контроль доступа, тегирование данных |
| Данные бухгалтерии | Финансовые потери | Шифрование данных, контроль доступа, тегирование данных |
| Данные учёта МТР | Финансовые потери | Контроль доступа, тегирование данных |
