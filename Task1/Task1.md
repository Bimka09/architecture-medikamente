# 1. Анализ безопасности системы

## 1. Выявление конфиденциальных данных

В системе обрабатываются и хранятся следующие типы данных:
1) Персональные данные (PII):
    - ФИО
    - Дата рождения
    - Контакты, адрес
    - Паспортные данные

2) Медицинские данные (СПДн):
    - Диагнозы
    - Результаты анализов
    - Истории болезней
    - Заключения врачей

3) Финансовые данные:
    - Реквизиты договоров
    - История платежей

4) Данные ТМЦ:
    - Информация о закупках оборудования и медикаментов

Составлены DFD диаграммы по каждому процессу, который взаимодействует с данными.

## 2. Аудит по обеспечению безопасности данных

Выявленные проблемы с данными:
1. Данные не защищены — хранятся в открытом виде, нет шифрования
2. Нет контроля доступа — любой сотрудник может получить доступ ко всем данным
3. Нет аудита — не понятно, кто и когда что-то смотрел или менял
4. Небезопасная передача — данные передаются без шифрования
5. Смешаны разные типы данных — медицинские, финансовые и складские данные в одном месте
6. Ручная обработка — высокий риск ошибок
7. Нет резервного копирования - риск потери данных

## 3. Улучшения

Защита данных:
1) Персональные данные (PII): 
    - Шифрование AES-256
    - TLS 1.3 
    - Обезличивание для аналитики

2) Медицинские данные (СПДн): 
    - Шифрование AES-256
    - RBAC
    - Маскирование

3) Финансовые данные: 
    - Шифрование
    - Обфускация в логах

Тегирование данных для автоматической классификации:
- `pii::personal::registration` — персональные данные для регистрации
- `spdn::health::diagnosis` — медицинские диагнозы
- `financial::contract::billing` — финансовые данные

Теги помогают автоматически контролировать доступ и мониторить использование данных.

### Инструменты для защиты данных:

Инфраструктура:
- Шифрование дисков (BitLocker/LUKS)
- TLS 1.3 для всех соединений
- HashiCorp Vault для секретов

Базы данных:
- PostgreSQL с pgcrypto для шифрования
- Разделение данных по схемам
- Логирование в Elasticsearch

Процессы:
- DevSecOps: сканеры уязвимостей в CI/CD
- Управление согласиями в CRM
- Внедрить резервное копирование данных
